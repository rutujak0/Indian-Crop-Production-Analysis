Indian Crop Production Analysis

##Project Overview

This project focuses on analysing Indian agricultural crop production data using Python and Tableau to understand crop production patterns across different states, seasons, and crops.

The main objective is to explore agricultural trends, identify top-producing crops and states, and analyse the relationship between crop production, cultivated area, and yield.

##Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Tableau

##Project Components

1. Python Analysis

- Dataset loading and inspection
- Data understanding and exploration
- Data cleaning and preprocessing
- Missing value treatment
- Duplicate value identification and handling
- Exploratory Data Analysis (EDA)
- Data visualisation
- State-wise and crop-wise production analysis
- Season-wise crop production analysis
- Analysis of crop production and yield patterns

2. Tableau Dashboard

- Interactive agricultural analysis dashboard
- State-wise crop production analysis
- Top 10 crop production analysis
- Season-wise production analysis
- Crop-wise production and yield comparison
- Interactive filters for state, crop, and season
- Dynamic KPI updates based on selected filters
- Interactive map for geographical analysis
- URL actions to explore additional information about selected crops

- Python_Analysis

##Conclusion

This project combines Python-based data analysis and Tableau dashboard development to explore Indian agricultural production patterns. It provides interactive visual insights into crop production across different states, crops, and seasons, helping users understand agricultural trends and make data-driven observations.
